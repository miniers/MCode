# 高还原设计稿

1. 不画 ASCII 线稿。UI 方案写成 HTML 文件，放在 `docs/design/<主题>.html`，一个方案一个文件；同一方案的多个状态或视口并排放在同一个文件里。
2. 先找项目真实的设计 token：CSS 变量文件、Tailwind 配置、主题文件或组件库样式。能引用就用相对路径 `<link>` 引用，只能抄值时照原值抄，不自造颜色、字号、间距、圆角。项目没有 token 时，在文件顶部用 CSS 变量集中定义一套。
3. 交互用原生 JS 写在同文件的 `<script>` 里（展开收起、选中、悬停、状态切换）。不引用外链 CDN、远程字体，不发网络请求，预览的 CSP 会拦截；图标用内联 SVG。
4. 写完调用 mcode 的 `preview_open` 工具打开设计稿；工具不可用时在回复里用反引号给出文件路径，用户点击即可预览。用户可用标注圈选元素回传修改意见。
